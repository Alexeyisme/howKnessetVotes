# Security

Please report vulnerabilities in the site (knessetvotes.org), its API or this code privately through GitHub:
**Security → Report a vulnerability** in this repository. Do not open a public issue for them.

Mistakes in the data (a wrong vote, name, faction or translation) are not security issues: use the
"suggest a correction" link on the site (or https://knessetvotes.org/en/suggest), or open an issue.
